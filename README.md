# Restaurant-overview-classification-with-NLP

Цель данного проекта поиск негативных отзывов среди отзывов на рестораны. Такая модель может помочь бизнесу находиться свои недочёты и исправлять их. 

Исходя из такой цели метрикой качества модели был выбран precision (особенно для класса негативных отзывов). Для нас не так важны нейтральные или положительные отзывы, нас интересуют только негативные отзывы и мы хотим, что бы наша модель была сильно уверена в предсказании негативных отзывов.
